CONFIGURACIÓN REQUERIDA
Falta conectar Firebase
Para que el sorteo funcione entre distintos dispositivos, pega la configuración de tu proyecto de Firebase dentro del archivo.
  1. Abre index.html con un editor de texto.
  2. Busca el bloque FIREBASE_CONFIG al inicio del <script>.
  3. Reemplaza los valores "TU_..." por los de tu proyecto (los obtienes en la consola de Firebase).
  4. Guarda el archivo y vuelve a abrirlo.
Sigue la guía que te dieron en el chat para crear el proyecto de Firebase paso a paso.
